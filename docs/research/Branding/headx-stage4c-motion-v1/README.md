用法：用瀏覽器打開 edit.html。資料存在瀏覽器 localStorage；換瀏覽器請用「匯出／匯入 JSON」。
前階段：若 localStorage 已有 brand_brief_stage0／1／2／3／4a／4b 會自動讀取；也可在側欄手動匯入各階段 brief JSON。匯入 4B 時，若漸變欄位空白，會自動帶入 4B 的漸變色標與文字色。

重要限制
- 時長、緩動曲線、效能等級（1–3）是常見起點與一般經驗，須用瀏覽器開發工具與真實裝置實測。
- 常見無障礙原則（非法律意見）：每秒不超過 3 次閃光（WCAG 2.3.1）；自動開始、超過 5 秒、與其他內容並行的動態須可暫停、停止或隱藏（WCAG 2.2.2）；預錄影片的人聲須有字幕；使用者開啟系統「減少動態」時須有替代版本。
- 影片尺寸與安全區（如 9:16 的 1080×1920、上約 14%／下約 35%）來自公開指南的常見做法，各平台與年份不同，須以最新平台說明為準。響度（LUFS）目標隨平台不同，原型不提供固定數字，只列常見參考並要求查證。
- 動態與聲音預覽只是草圖，不是品牌聲音或成品。聲音設計（作曲、錄音、混音）與影片製作須由專業人士完成。
- 音樂、人聲、肖像與 AI 生成素材的授權（媒體、地區、期限、商用、廣告）與披露須書面確認；AI 合成人聲不可用於客人見證；健康與效果相關的見證與前後對比須人類合規審核。
- 沒有風格相符度分數；AI 提案不等於核准；approval.state 固定為 draft。
- 選項內容是通用知識的起始草案，尚未逐項來源查證。
- 4D–4H 不會自動讀取本階段；請匯出 stage4c-brief.json 帶過去。

測試：已用 Chromium（Playwright）開過 edit／view／agent 三頁：點擊選項、匯入 4B、動態實驗室與漸變預覽播放／暫停／模擬減少動態、節奏換算、貼回 JSON、重新載入保存，均無 console 錯誤；手機寬度（390px）三頁都沒有橫向捲動。未做 Safari／Firefox、螢幕閱讀器、真實裝置效能、真實聲音與影片製作，以及用 Stage 1–3 真實 brief 的驗收。
