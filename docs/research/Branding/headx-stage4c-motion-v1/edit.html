動態、聲音與影片

把 4A、4B 的視覺與表面規格延伸到時間與聲音：動態風格與 token（緩動、時長、編排、位移）、減少動態版本、漸變／紋理／形狀的動態（含動畫全程對比檢查與效能等級）、影片風格與格式、運鏡／燈光／構圖／氣氛、剪接與節奏（BPM 換算）、字幕與無障礙、聲音（音樂、樂器、音色、旁白、介面音效、靜默、響度）與授權。每個決策有討論提示詞；完成後輸出動態 token、motion／video／sound spec、Video Prompt、Audio Prompt 與設計 Agent 規則。

注意：原型資料只存在你的瀏覽器。選項內容是通用知識的起始草案，尚未逐項查證。時長、緩動曲線與效能等級是常見起點與一般經驗，須實測；影片比例、安全區與響度目標隨平台與年份不同，須以最新平台說明為準。閃爍上限（每秒不超過 3 次）、自動播放超過 5 秒須可暫停、有人聲須有字幕，是常見的無障礙要求，不是法律意見。聲音與動態預覽只是草圖，不是品牌聲音或成品；聲音設計與影片製作須由專業人士完成；音樂、人聲、肖像與 AI 素材須書面確認授權與披露。沒有風格相符度分數。AI 提案不等於核准。
