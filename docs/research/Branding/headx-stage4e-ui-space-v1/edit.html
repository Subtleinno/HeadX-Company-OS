UI／UX 與空間體驗

把 4B 的圓角比例尺、陰影、邊框、焦點外框與填色狀態，轉成元件規範，並逐狀態做顏色對比檢查（文字 4.5:1、元件與焦點 3:1、目標大小）；再延伸到 UX 模式、客戶旅程與服務藍圖、空間（分區、材質、燈光、感官、客流容量、尋路與無障礙，附香港建築署手冊公開數值對照）。每個決策有討論提示詞；完成後輸出 UI tokens CSS、component-spec、無障礙測試計畫、旅程 CSV、space-spec、UI／空間 Prompt 與設計 Agent 規則。

注意：原型資料只存在你的瀏覽器。選項內容是通用知識的起始草案，尚未逐項查證。對比檢查只涵蓋顏色；鍵盤、螢幕閱讀器、焦點行為與真人測試必須由人類執行，原型不能宣稱「已符合 WCAG」。WCAG 2.2 數值（4.5:1、3:1、24×24 CSS px 等）只是設計門檻。實體空間的建築、消防、電氣、衛生、無障礙與規管要求須由註冊專業人士確認；建築署手冊數值是公開摘錄，以最新版為準，不是法律意見。旅程表的內容須來自真實觀察或標示為假設。沒有風格相符度分數。AI 提案不等於核准。
