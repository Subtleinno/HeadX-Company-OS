# Stage 01 · 品牌定位與核心張力

檔案
- edit.html   編輯（11 張卡片 + 完成度 + 貼回 AI 結果 + 匯入/匯出）
- view.html   展示頁（定位宣言、邏輯一覽、張力刻度視覺化、避雷清單）
- agent.html  AI Agent 合約（brand-brief.json + 下游系統提示詞）
- options.js  全部選項與說明（可直接增刪）
- core.js     狀態、完成度、定位宣言草稿、貼回解析、brief 產生
- prompts.js  11 份討論提示詞（角色／目的／原因／現況／清單／規則／步驟／交付／JSON／生圖）
- shared.css

用法：用瀏覽器打開 edit.html。資料存在瀏覽器 localStorage；換瀏覽器請用「匯出／匯入 JSON」。
結構依據：Dunford 五要素（競品替代、獨特屬性、價值、最適客群、市場類別）與標準定位宣言；痛點分類依 Jobs-to-be-done。
