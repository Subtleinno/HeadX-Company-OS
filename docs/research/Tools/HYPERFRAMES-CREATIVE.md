# HYPERFRAMES-CREATIVE.md — 適合 HyperFrames 的創意方向

> 目的：讓 agent 知道「什麼創意適合用 HTML 渲染」，避免提出做不到或不划算的東西。
> 這是我們的設計建議（未經官方驗證），請在實測後調整。

## 1. 先問：這個創意適合 HyperFrames 嗎？

適合（可程式化、可重複、可變數化）：
- 字體動效、字卡、標題、字幕、卡拉 OK 字幕
- 數據：圖表、計數器、排行榜、時間線、地圖路線
- UI 示範：App/網站截圖動畫、游標、點擊、程式碼 diff
- 產品介紹：規格卡、功能對比、價格卡、3D 轉盤（Blender 影片或 Three.js）
- 品牌系統動態：Logo 動效、轉場、色塊轉場、Lottie 圖標
- 系列化內容：同一模板 × 多組資料（每週報告、每日優惠、每款產品）

不適合（改用其他工具產出素材，再放進 composition）：
- 真人、寫實場景、自然物理（用拍攝、Blender、AI 影片模型）
- 複雜粒子、流體（用 Blender / TouchDesigner 預渲染）
- 需要每幀即時隨機且不可重現的效果

## 3. Agent 創作指引

1. 先決定「一個主要概念」（例如：數字增長、產品轉動、文字節奏），再選 runtime。
2. 一支片不要混用超過三種風格。品牌色最多 3 種主色。
3. 節奏：每 2–4 秒一個視覺變化；重點字停留至少 1.2 秒。
4. 音樂與旁白決定剪點，先有音頻再排畫面。
5. 每個場景結尾要留出轉場的空間。
6. 優先使用 Catalog 現成區塊，再修改成品牌風格。
7. 生成後一定看 snapshot：文字溢出、對比、裁切、品牌色。

## 4. 與 Blender / Lottie 的組合創意

- **Blender 產品轉盤 + HyperFrames 字卡**：3D 部分預渲染成 MP4，字卡與規格用 HTML 疊上。
- **Lottie 圖標系列 + 同一份 JSON 放進網站**：影片與網站視覺一致。
- **Blender 無縫圖案作為動態背景**：緩慢位移的背景層。
- **Blender 導出 GLB → Three.js 旋轉 + 相機運動**：適合輕量產品，檔案小。
- **數據驅動的 Mascot 動作**：Lottie 或 PNG 序列，按文案情緒切換。
