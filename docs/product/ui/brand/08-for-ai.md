# 08 給 AI 用區

品牌主頁底部與各頁可展開。

```
+--------------------------------------------------------------+
| 給 AI 用                                                     |
+--------------------------------------------------------------+
| 組成：平台 v4, 色彩 v7, 字體 v5, 標誌 v3, 語氣 v6, 圖像 v2   |
| [品牌 prompt]  [tokens]  [缺口]                              |
| +----------------------------------------------------------+ |
| | <品牌 prompt 內容，含立場、用色順序、字體分工、           | |
| |  最小尺寸、對比下限、語氣樣本、禁止、缺口>               | |
| +----------------------------------------------------------+ |
| [複製]  [下載 tokens.json]  [下載 A4 PDF]                    |
+--------------------------------------------------------------+
```

## 規則
- 一定顯示由哪些頁哪個版本組成。
- 缺的項目出現在缺口分頁，不出現在 tokens。
