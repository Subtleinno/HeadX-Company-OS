# 08 給 AI 用

圖：`png/08-for-ai.png`

## 進入方式
品牌主頁底部「給 AI 用」卡按「展開」，或從任何頁的「匯出」選單進入。

## 版面
- 標題「給 AI 用」，副標「品牌 prompt 與 tokens，由各頁的現行版本組成。」
- 單張卡：分頁「品牌 prompt」「tokens」「缺口 N」。
- 組成列：「組成：平台 v4　色彩 v7　字體 v5　標誌 v3　圖像 v2」。
- 內容區（等寬字）：品牌 prompt 全文。內容必須包含立場、用色順序、對比下限、字體分工、標誌最小尺寸、語氣樣本、禁止事項與缺口。缺的項目寫明「缺」，不可自行補上。
- 按鈕：「複製」（藍色）、「下載 tokens.json」、「下載 A4 PDF」。

## 規則
- 一定顯示由哪些頁哪個版本組成。
- 缺的項目只出現在「缺口」分頁與 prompt 的缺口段落，不出現在 tokens。
- tokens 分頁顯示 W3C Design Tokens 格式預覽，淺色與深色兩套。

## 驗收
- 改色彩頁一個角色，prompt、tokens、HTML 三者同步變化。
