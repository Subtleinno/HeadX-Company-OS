# 09 策略頁（Boss Portal）

只有老闆可編輯；其他人只讀或看不到。

```
+--------------------------------------------------------------+
| 策略                                                         |
+------------------+-------------------------------------------+
| 平台       v2    | 槽：色彩        版本 v3  [版本記錄]       |
| 色彩       v3    |                                           |
| 字體       v2    | <長文字編輯區>                            |
| 標誌       v2    |                                           |
| 圖像       缺    |                                           |
| 語氣       v1    |                                           |
| 品牌主頁   v2    | 最近用了這份策略的頁：色彩 v7, 色彩 v6    |
| 應用       缺    |                                           |
| 自定義頁   v1    | 規則 id：color.r1 ... color.r4  [對照]    |
|                  |                       [儲存為新版本]      |
+------------------+-------------------------------------------+
```

## 規則
- 每次儲存是新版本，只加不改。
- 缺的槽顯示「缺」，不顯示「未寫」。
- 改策略不改已完成頁；頁顯示「用的是舊策略版本」提示。
