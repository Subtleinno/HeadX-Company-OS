# 09 策略（Boss Portal）

圖：`png/09-strategy.png`

## 進入方式
Boss Portal →「策略」。只有老闆可進入並編輯；其他人看不到入口，直入網址見具體原因的權限狀態。

## 版面
- 頂欄：Boss Portal；範圍位為純文字「公司範圍」，沒有品牌 Logo。
- 標題「策略」，副標「只有老闆可以修改。每次儲存都是新版本。」
- 三欄：
  1. 槽列表（260px）：平台、色彩、字體、標誌、圖像、語氣、品牌主頁、應用、自定義頁通用；右側顯示版本號，缺的顯示橙色「缺」。
  2. 編輯區：槽名、版本小標籤、「版本記錄」；長文字編輯框；藍色按鈕「儲存為新版本」。
  3. 右欄：「最近用了這份策略的頁」列表；「規則」卡列出此槽所有規則 id 與「有檢查」小標籤。

## 規則
- 每次儲存是新版本，只加不改。
- 缺的槽顯示「缺」，不顯示「未寫」。
- 改策略不會改已完成的頁；那些頁顯示「用的是舊策略版本」。
- 規則 id 必須都有對應 checker；缺 checker 的 id 顯示橙色「無檢查」。

## 驗收
- 非老闆無法編輯，也看不到入口。
- 儲存後版本記錄多一筆，舊版本不變。
