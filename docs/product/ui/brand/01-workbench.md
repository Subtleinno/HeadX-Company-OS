# 01 品牌工作台

打開 Design 的第一屏。直接進上次使用的品牌，不顯示品牌清單。

```
+--------------------------------------------------------------+
| [品牌名 v]                                   缺口 3  [設定]   |
+--------------------------------------------------------------+
|                                                              |
|   用一句話說你想做什麼                                        |
|   +--------------------------------------------------+  [→]  |
|   |                                                  |       |
|   +--------------------------------------------------+       |
|                                                              |
|   進行中的作品                                                |
|   +---------+  +---------+  +---------+                      |
|   | 縮圖    |  | 縮圖    |  | 縮圖    |                      |
|   | 標題    |  | 標題    |  | 標題    |                      |
|   | 品牌v12 |  | 品牌v12 |  | 品牌v11 |                      |
|   +---------+  +---------+  +---------+                      |
|                                                              |
|   [打開品牌主頁]                                              |
+--------------------------------------------------------------+
```

## 資訊層級
- 最重要：輸入框。
- 次要：進行中作品（顯示它用的品牌版本）。
- 可折疊：缺口數（點開到缺口總覽）。

## 狀態
- 沒有任何品牌：只有老闆看到「開新品牌」，其他人看到「請聯絡老闆」。
- 作品用的品牌版本已不是現行：縮圖旁標「用舊版 v11」。
