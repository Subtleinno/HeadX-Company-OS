# 04 版本抽屜

從任何頁的版本標籤打開，右側滑出。

```
+---------------------------+
| 版本               [x]    |
+---------------------------+
| v7  現行  Amy  11/11      |
|     策略 v3   被引用 2    |
| v6        Amy  11/09      |
|     策略 v3   被引用 1    |
| v5        Ben  11/02      |
|     策略 v2   未被引用    |
|                  [刪除]   |
+---------------------------+
| 點一個版本：顯示與現行的   |
| 欄位差異（改了哪個欄位）   |
+---------------------------+
```

## 規則
- 現行版本沒有 [刪除]。
- 未被引用的版本可刪。
- 被引用的版本先顯示誰引用（成品名稱、品牌主頁版本），確認後才刪；刪後引用處標「缺版本」。
- 已出街成品固定顯示它釘住的版本。
