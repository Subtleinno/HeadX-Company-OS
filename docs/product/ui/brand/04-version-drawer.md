# 04 版本抽屜

圖：`png/04-version-drawer.png`

## 進入方式
任何品牌頁頂部的「版本」按鈕，右側滑出抽屜（寬 460px），底下頁面變暗。

## 版面
- 標題「版本」＋關閉按鈕。
- 版本卡：版本號、「現行」綠色小標籤、修改者與日期、「用策略 vN」、引用小標籤（「被引用 2」或「未被引用」）。
- 非現行版本右下顯示「刪除」（紅字外框按鈕）。現行版本沒有刪除按鈕。
- 被引用版本按下「刪除」，卡下方出現橙色提示：「刪除 v6 後，海報〈夏季療程〉會標示『缺版本』。」＋「取消」「仍然刪除」。
- 抽屜底部「vX 與現行 vY 的差異」卡：列出改了哪個欄位，不顯示整頁差異。

## 規則
- 現行版本不能刪。
- 未被引用的版本直接刪除（仍需一次確認）。
- 被引用的版本先說明影響，刪除後引用處標「缺版本」。
- 已出街成品固定顯示它釘住的版本。

## 驗收
- 現行版本沒有刪除按鈕。
- 刪除被引用版本時一定先看到影響說明。
