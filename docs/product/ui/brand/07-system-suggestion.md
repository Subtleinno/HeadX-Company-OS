# 07 專屬系統建議卡

agent 認為某個品牌專屬系統值得獨立成頁時，在品牌主頁出現。

```
+--------------------------------------------------------------+
| 建議新增一頁：<標題>                                         |
| 為什麼獨立：<獨有 / 重複使用 / 其他頁放不下，各一句>          |
| 邊界：不決定色、字、標誌、語氣；會引用 brand.primary, ink..  |
|                              [略過]   [接受並建立]           |
+--------------------------------------------------------------+
```

## 規則
- 接受後建立自定義頁，並寫入一句 brief。
- 略過會記錄，內容無明顯變化不再出現。
