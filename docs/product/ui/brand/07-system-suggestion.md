# 07 專屬系統建議

圖：`png/07-system-suggestion.png`

## 進入方式
agent 判斷某個品牌專屬系統值得獨立成頁時，在品牌主頁開啟此對話框（寬 640px）；也可由 Needs 欄通知進入。

## 版面
- 標題「建議新增一頁：天空漸層」，副標說明 agent 在標誌、色彩、字體和語氣之外找到一個品牌專屬系統。
- 判斷三項（綠色「是」＋一句理由）：獨有、重複使用、其他頁放不下。三項皆是才會出現此建議。
- 「邊界」卡：不決定顏色、字體、標誌或語氣；列出會引用的角色（paper、ink、brand.primary）。
- 「這頁決定什麼（一句）」輸入框，預填 agent 的 brief，可修改。
- 底部：「略過」（外框）、「接受並建立」（藍色）。

## 規則
- 接受後建立自定義頁，並把 brief 寫入該頁；左側欄「品牌專屬 CUSTOM」組出現新頁。
- 略過會記錄；內容沒有明顯變化不再出現。
- 若 agent 判斷其實屬於既有頁，不顯示此對話框，改在該頁頂部提示「這屬於色彩頁」。

## 權限
老闆與品牌設計師。

## 驗收
- 三項判斷缺一項就不出現建議。
- 接受後品牌主頁入口自動出現新頁。
