# 05 立場句選擇

新品牌或重編時出現。

```
+--------------------------------------------------------------+
| 選一句，作為這個品牌的立場                                    |
+--------------------------------------------------------------+
| ( ) 候選 1：<立場句>                                         |
|     為什麼：<一行理由>                                       |
| ( ) 候選 2：<立場句>                                         |
|     為什麼：<一行理由>                                       |
| ( ) 候選 3：<立場句>                                         |
|     為什麼：<一行理由>                                       |
| ( ) 我自己寫：[______________________]                       |
|                                                              |
| 定位三檢：真實 [證據]  相關 [證據]  獨特 [證據]              |
|                                  [重新產生]   [確定]         |
+--------------------------------------------------------------+
```

## 狀態
- 三檢缺證據：顯示「缺（判斷型）」，只有老闆可關閉，帶 [建立 Need]（指派老闆）。
- 確定後寫入平台頁 payload，產生新版本。
