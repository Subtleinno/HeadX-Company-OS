# 05 立場句選擇

圖：`png/05-stance-picker.png`

## 進入方式
新品牌建立後、或在平台頁按「重新產生立場」。對話框（寬 720px）置中，底下頁面變暗。

## 版面
- 標題「選一句，作為這個品牌的立場」，副標「立場會成為每一頁的第一句。」
- 三個候選卡：立場句（Serif 20px）＋一行理由。選中卡藍框淡藍底，單選圓點。
- 第四項「或自己寫一句⋯」輸入框。
- 「定位三檢」三張小卡：真實、相關、獨特。有證據的顯示綠色「真實」「相關」＋一句證據；缺證據的顯示橙色「獨特　缺」、說明「只有老闆可補」＋「建立 Need」。
- 底部：「重新產生」（外框）、「確定」（藍色）。

## 規則
- 立場句由老闆或品牌設計師選定；候選由 agent 產生，每個附理由。
- 三檢缺證據時仍可確定，但平台頁顯示缺口。
- 確定後寫入平台頁 payload，產生新版本，各頁第一屏沿用。

## 權限
老闆與品牌設計師。判斷型缺口的 Need 預設指派老闆。

## 驗收
- 三個候選都有理由。
- 缺證據的一檢可建立 Need。
