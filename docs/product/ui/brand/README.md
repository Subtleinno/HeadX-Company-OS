# 品牌模組 v2 UI 設計稿

狀態：初版線框（只有結構與資訊層級，沒有顏色與字體）。老闆可以直接改這些檔，或放入自己的設計稿覆蓋。

## 規則
- 檔名：`NN-畫面名.md`，或以 issue 號開頭。放圖片時與同名 md 放同一資料夾。
- 這些線框是 Issue 14 的對照依據。與 issue 衝突或缺畫面，Workbuddy 停下回報，不自己決定。
- 線框只決定結構與資訊層級。視覺（色、字、間距）用現有 Company OS 的設計系統，品牌內容區由 payload 渲染，不受外框影響。
- 外框保持中性，不搶品牌內容的風頭。

## 通用原則
1. 內容是主角，外框用最少的線與色。
2. 缺就明說「缺」，並帶「建立 Need」入口，不用灰色假內容。
3. 每頁看得到版本與最後修改者。
4. 不要儀表板、不要渠道、不要把品牌清單當首頁。
5. 手機寬度可讀品牌主頁；編輯只要求桌面。
