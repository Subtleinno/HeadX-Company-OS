# 06 缺口與 Need

品牌層缺口總覽，以及頁內缺口的樣子。

```
品牌缺口總覽
+--------------------------------------------------------------+
| 缺口 3                                                       |
+--------------------------------------------------------------+
| 型別  頁    缺什麼              規則   Need 狀態     動作      |
| 檔案  標誌  主標誌 SVG          logo.r1 未建立      [建立Need]|
| 檔案  字體  中文字體網頁授權    type.r3 進行中(外判)  [查看]   |
| 判斷  平台  定位的獨特證據      platform.r1 進行中(老闆) [查看]|
+--------------------------------------------------------------+

頁內缺口
+------------------------------------------+
| 缺：主標誌 SVG                           |
| 原因：沒有檔案                           |
| 要交付：向量檔 SVG                       |
|                         [建立 Need]      |
+------------------------------------------+
```

## 規則
- 一個缺口只有一個進行中的 Need；已建立則按鈕改為 [查看]。
- 檔案型：外判可交付，設計師或老闆接受後關閉。
- 判斷型：只有老闆可關閉。
- Need 交付後內容回到該頁，頁頂出現「待接受」。
