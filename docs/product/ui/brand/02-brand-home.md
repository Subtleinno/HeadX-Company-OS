# 02 品牌主頁

全幅顯示由 payload 渲染的品牌主頁。外框只有一條細欄。版面由 layout 決定，下圖只畫外框，不畫內容。

```
+--------------------------------------------------------------+
| 品牌名  v12 現行   [編輯]  [提示：色彩頁已改，需重編]  [PDF] |
+----------+---------------------------------------------------+
| 平台     |                                                   |
| 色彩     |   <第一屏：立場句>                                 |
| 字體     |                                                   |
| 標誌     |   <由 layout 決定的區塊：                         |
| 語氣     |    關鍵詞 / 用色順序 / 標誌用法 /                 |
| 圖像     |    字體分工 / 專屬系統 / 語氣短例 ...>            |
| 自定義.. |                                                   |
| 缺: 標誌 |   <缺口區：缺什麼 [建立 Need]>                    |
|          |                                                   |
|          |   <給 AI 用區：見 08>                              |
+----------+---------------------------------------------------+
```

## 資訊層級
- 最重要：立場句（第一屏）。
- 次要：各頁入口（左欄）、缺口。
- 可折疊：給 AI 用區、驗證結果摘要。

## 狀態
- 頁缺：入口標「缺」，點進去說明缺什麼、誰可補、[建立 Need]。
- 需要重編：頂欄提示，不自動重寫。
- 手機：左欄收成頂部下拉；唯讀。
