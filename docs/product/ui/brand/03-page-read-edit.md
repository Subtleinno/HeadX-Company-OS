# 03 頁閱讀與編輯（含檢查）

圖：`png/03a-color-read.png`、`png/03b-color-edit.png`

適用平台、色彩、字體、標誌、語氣、圖像與自定義頁。以色彩頁為示範。

## 閱讀態（03a）
- 標題「色彩」，副標「版本 v7　現行　最後修改 Amy　11 月 11 日　用策略 v3」。動作：「版本」「編輯」。
- 檢查摘要條：「通過 8」「不通過 0」「無法判斷 1」＋一句最重要的說明＋「查看明細」。
- 內容區：立場句、用色比例、角色表。
- 角色表欄位：色樣、角色（附品牌色名）、螢幕值（HEX、RGB）、用途、理由。缺的角色顯示虛線色樣與「缺」，理由欄放「建立 Need」。

## 編輯態（03b）
- 標題下副標「正在編輯　以 v7 為基礎」。動作：「放棄」（外框）、「儲存為新版本」（藍色）。
- Needs 欄收起，騰出空間。
- 左：可直接改的欄位表。被人手改過的欄位用藍框淡藍底，旁邊小標籤「人手改過」。
- 右：「對這一段下指示」卡，說明「選取左邊一個角色，告訴 agent 要怎樣改。」，輸入框，藍色按鈕「交給 agent」。
- 檢查有不通過時，內容上方出現橙色橫幅，顯示規則 id、位置與怎樣改，右側小標籤「不通過」。

## 檢查明細
展開後逐條列出：規則 id、結果（通過、不通過、無法判斷）、位置、怎樣改。無法判斷的一條要連到對應缺口。

## 規則
- 儲存一定產生新版本，並記住所用策略版本。
- 人手改過的欄位，重編時以改過的為準。
- 檢查只報告，不阻止儲存。

## 權限
無編輯權限者沒有「編輯」按鈕。

## 驗收
- 改一個角色後儲存，版本差異只指出這個欄位。
- 不通過的規則顯示 id、位置與修正建議。
