# 03 頁閱讀與編輯

適用平台、色彩、字體、標誌、語氣、圖像與自定義頁。

```
閱讀態
+--------------------------------------------------------------+
| 色彩  v7 現行  最後修改 Amy 11/11   檢查: 通過 6 / 不通過 1 / 無法判斷 2 [展開] [編輯] |
+--------------------------------------------------------------+
|  <立場句>                                                    |
|  <由 layout 渲染的內容區，佔滿>                              |
+--------------------------------------------------------------+

編輯態
+--------------------------------------------------------------+
| 色彩  編輯中  [儲存為新版本] [放棄]                          |
+--------------------------------------------------------------+
|  內容區（可直接改欄位）        | 對這一段下指示                |
|  [人手改過] 標記               | +------------------------+   |
|                                | | 這段改成...            |   |
|                                | +------------------------+   |
|                                | [交給 agent]                 |
+--------------------------------------------------------------+
```

## 資訊層級
- 最重要：內容區。
- 次要：版本與最後修改者、檢查摘要。
- 可折疊：檢查明細（規則 id、位置、怎樣改）。

## 狀態
- 無編輯權限：沒有 [編輯]。
- 檢查「無法判斷」：明細連到對應缺口。
