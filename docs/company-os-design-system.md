# Company OS 設計系統（Design System）

版本：v0.1 草案 | 日期：2026-11-03 | 批准人：創辦人
適用範圍：Company OS 引擎及其所有子系統（政策閘道、批准收件匣、Company Dashboard、Needs、Super Agent 控制台），以及將來自家開發的任何 app。

> 這份文件是**硬規則**。任何 UI 交付若違反下列「禁止」清單，直接退回，不進入審批。

---

## 1. 設計信仰

1. **先制度，後個性**：所有介面先符合 Apple Human Interface Guidelines，再談品牌。
2. **減法優先**：能用留白解決的，不加邊框；能用文字解決的，不加圖示；能刪掉的，就刪。
3. **動效服務理解**：動畫只為「讓使用者知道發生了什麼」，不為炫技。
4. **AI 可讀**：每個畫面都必須能被 MCP 以結構化資料讀取，UI 不是唯一的入口。

---

## 2. 基礎規則（不可違反）

| 項目 | 規則 |
|---|---|
| **色彩** | 白底（`#FFFFFF`）+ 黑主色（`#000000`）。不引入第三種彩度色相作為品牌主色。 |
| **Emoji** | **全面禁止**，包括介面文字、按鈕、選單、通知、文件、提交訊息、程式註解。 |
| **圖示** | 只用線性圖示，線寬一致；不用擬真圖示。狀態圖示可跟隨狀態色。 |
| **對比度** | 文字與背景對比至少 4.5:1；大字至少 3:1（WCAG AA）。 |
| **字體** | 系統字體堆疊優先（Apple 平台用 San Francisco；跨平台退回 Inter / system-ui）。不引入裝飾字體。 |
| **圓角** | 統一使用 8 / 12 / 20 三級，不任意取值。 |
| **陰影** | 只用於表達層級（浮層、卡片）；禁止裝飾性陰影。 |
| **動效** | 使用 GSAP；時長 120–320ms；緩動以 ease-out 為主；尊重 `prefers-reduced-motion`。 |

## 3. 顏色權杖（Design Tokens）

```
--surface-base       #FFFFFF   頁面底色
--surface-raised     #FAFAFA   卡片／浮層
--surface-sunken     #F5F5F5   輸入框、次層背景
--text-primary       #000000   主要文字
--text-secondary     #6E6E73   次要文字（Apple 中性灰）
--text-tertiary      #AEAEB2   說明文字
--border-subtle      #E5E5EA   分隔線
--border-strong      #1C1C1E   強調邊框
--accent             #000000   主色（黑）
--accent-contrast    #FFFFFF   反白文字
--state-success      #0A7D32   成功（綠，WCAG AA 於白底）
--state-warning      #8A5A00   警告（琥珀，WCAG AA 於白底）
--state-danger       #C41E1E   錯誤／危險（紅，WCAG AA 於白底）
```

**定位：白底黑 accent 是「預設模式」，不是「唯一模式」。**

| 模式 | 何時使用 | 色彩 |
|---|---|---|
| **Default（預設）** | Company OS 控制台、政策閘道、批准收件匣、Dashboard、Needs | 白底、黑 accent、狀態用上表三色 |
| **Brand（品牌）** | 正在編輯某個品牌的事物（品牌素材、對外頁面、設計稿、品牌報告） | 讀取該品牌的 `brand.config` tokens：主色、字型、圓角、動效；結構規則不變 |

- 進入 Brand 模式時，介面**必須明確標示**（標題列顯示品牌名與品牌色點），避免使用者混淆「這是我的控制台還是客戶的品牌」。
- 離開品牌編輯即回到 Default 模式。
- **狀態色在兩種模式下都保留**：品牌色只取代「accent 與品牌裝飾」，不取代成功／警告／危險的語意色——否則使用者會失去「出事」的直覺。

**可及性要求**：狀態色必須同時配合圖示或文字標籤，不得只靠顏色傳達（色盲友善）。

> 例外：資料視覺化（圖表）可使用灰階連續色階；若必須區分，使用 `#000` / `#6E6E73` / `#AEAEB2` / `#E5E5EA` 四級。

## 4. 間距與排版

- 間距採用 4 的倍數：`4 / 8 / 12 / 16 / 24 / 32 / 48 / 64`
- 行高：正文 1.5；標題 1.2
- 字級階級：`34 / 28 / 22 / 17 / 15 / 13 / 11`（呼應 Apple macOS/iOS 的標題—正文—註腳階級）
- 每行文字寬度不超過 72 個字元

## 5. 版面骨架

```
┌──────────────────────────────────────────────┐
│ 標題列：品牌名（粗體）＋麵包屑＋單一主動作      │
├────────────┬─────────────────────────────────┤
│ 側欄       │ 內容區                           │
│ 公司       │                                 │
│  品牌 A    │  清單／表格／詳情                │
│  品牌 B    │                                 │
│ Apps       │                                 │
│ Needs      │                                 │
├────────────┴─────────────────────────────────┤
│ 狀態列：熔斷狀態、同步狀態、今日批准進度         │
└──────────────────────────────────────────────┘
```

- **單一主動作原則**：每個畫面只有一個黑色實心按鈕（主動作），其餘為線框或純文字按鈕。
- **破壞性動作**（刪除、撤回、停用）一律放在詳情頁的次要位置，不用紅色，但需二次確認並要求輸入理由。

## 6. 動效規範（GSAP）

| 情境 | 時長 | 緩動 | 說明 |
|---|---|---|---|
| 頁面切換 | 240ms | ease-out | 淡入 + 向上位移 8px |
| 卡片展開詳情 | 280ms | ease-in-out | 高度自適應，不彈跳 |
| 清單項目載入 | 320ms | ease-out | 交錯 20ms |
| 批准成功 | 180ms | ease-out | 按鈕狀態轉換，不慶祝、不撒彩帶 |
| 錯誤提示 | 120ms | linear | 邊框加粗，不抖動 |

**禁止**：彈簧過度回彈、粒子效果、載入時的全屏動畫、無意義的視差滾動。

## 7. AI 原生（MCP）規則

1. **每個 app 必須出一個 MCP 伺服器**，使用最新 MCP 規範，工具描述要能被模型直接理解。
2. **UI 與 MCP 共用同一個核心**：UI 的所有操作，MCP 都有對應的工具；但 **MCP 不得提供「批准」與「撤銷批准」**，這兩個動作永遠只經人。
3. **MCP 工具必須**：有型別化參數、幂等鍵、回傳結構化結果（含 `request_id` 以便對應審計日誌）、失敗要有明確錯誤碼。
4. **Dashboard 的資料**同時提供 `dashboard.snapshot` MCP 工具，讓 Super Agent 能讀取「現在公司狀態」而不必爬網頁。

## 8. 品牌適配（可控制設計系統）

雖然 Company OS 本身固定白底黑主色，但**各品牌對外輸出需要品牌個性**。做法：

- Company OS 控制台：**永遠**白底黑 accent（上述 token）。
- 品牌層（HxDesign 產出、對外網站、設計素材）：讀取 `brand.config` 的 **brand tokens**，可自訂主色、字體、圓角、動效風格。
- 兩者的**結構規則**（間距、對比、動效時長範圍、可及性）完全相同，只有**顏色與字型**可換。

> 換句話說：**制度統一、皮膚可換。**

---

## 9. 驗收清單（設計交付前自檢）

- [ ] 預設模式：白底、黑 accent，狀態色只用在狀態
- [ ] 若在品牌編輯模式：有明確標示，且品牌 tokens 來自 `brand.config`
- [ ] 狀態不以顏色單獨表達（同時有圖示或文字）
- [ ] 全畫面無 emoji（含 placeholder、tooltip、toast、空狀態）
- [ ] 每個畫面只有一個黑色實心主按鈕
- [ ] 文字對比度達 AA
- [ ] 動效時長在 120–320ms 內，並尊重 reduced-motion
- [ ] 破壞性動作需二次確認
- [ ] 該 app 已有對應 MCP 工具，且不含批准類工具
- [ ] 手機寬度（390px）下可用
- [ ] 鍵盤可達（Tab 順序合理、焦點可見）
